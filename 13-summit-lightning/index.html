Modern Network Protocols

Where Firefox (and the Internet?) is heading

Mozilla Engineering Summit · Lightning talk  ·  Max Inden, Firefox networking team (Necko)
I have given the long version of this talk many times: at universities, at FOSDEM, and elsewhere. This is the five-minute version. Goal: spark interest, not explain in depth. You should leave with more questions than answers; bring them to #necko.

HTTP everywhere

  • HTTP is the thin waist of the Internet: consistent, extensible, a strong security model, hard to censor.
  • More and more protocols move to HTTP:
    • DNS: DNS over HTTPS
    • Web apps’ own protocols: WebTransport
    • Proxied TCP and UDP: MASQUE

HTTP is the thin waist, and we keep putting more on top of it: DNS, web apps, proxying.

QUIC and HTTP/3  0-RTT

  • Transport on UDP, encrypted down to the packet headers.
  • 1-RTT connection setup, 0-RTT on resumption: the request goes out with the first packet.
  • No head-of-line blocking between streams.
  • Our QUIC stack is neqo, in Rust.
  • About 30% of Firefox requests use HTTP/3, in line with Cloudflare.
About a third of our traffic is HTTP/3 already. 0-RTT: on a repeat visit the request goes out with the handshake.

Happy Eyeballs v3

  • Tries all permutations of IPv4 and IPv6, TCP and QUIC, A, AAAA and HTTPS records, and keeps whatever connects first.
  • A sans-I/O Rust library: mozilla/happy-eyeballs.
  • Follows the IETF draft draft-ietf-happy-happyeyeballs-v3.
  • On in Nightly, rolling out on Beta and Release.
  • With DoH, HTTP/3 share of page loads goes from 16.6% to 27.9%.
One state machine decides how to connect. The Beta experiment shows the win: far more HTTP/3, most of all with DoH.

HTTPS records and ECH

  • The DNS HTTPS record (RFC 9460) can signal HTTP/3 support before the first connection. Alt-Svc signals HTTP/3 on the second connection only.
  • It also carries the key for Encrypted Client Hello (ECH), which hides the server name. ~16% of HTTPS records carry one (GLAM).
  • Check a domain: savearoundtrip.com.
  • DNS over HTTPS: see Valentin’s talk.
Most sites announce HTTP/3 only via Alt-Svc, which costs a round trip on first visit. HTTPS records fix that and enable ECH. DoH: Valentin.

WebTransport

  • Streams and datagrams for web apps, over HTTP/3. No head-of-line blocking.
  • HTTP/2 fallback upcoming (bug 2071107).
  • In all major browsers since March 2026; W3C Candidate Recommendation.
  • Emerging consumer: Media over QUIC.

MASQUE

  • Proxy TCP (connect-tcp) and UDP (connect-udp) through HTTP.
  • Firefox VPN uses classic CONNECT over HTTP/2 today. Next: HTTP/3 support through MASQUE (bug 1978893).
  • Many ways to reach one site: HTTP/1.1, HTTP/2 or HTTP/3; direct, CONNECT or MASQUE; to a proxy over HTTP/1.1, HTTP/2 or HTTP/3.
